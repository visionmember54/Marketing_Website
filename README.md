# Kalyan Milan marketing website

This is a self-contained static marketing site with two pages:

- `index.html` — long-form responsive landing page with app highlights, game formats, market overview, session details, screenshots, FAQs, and download links.
- `app-download.html` — a light app listing page with the supplied Kalyan Milan promotional images in `images/`.

Open `index.html` directly in a browser or serve this folder with any static web server. The official app store/APK URL has not been supplied, so download links point to the known official website for installation information. Replace that destination with the verified direct download URL when it is available. Live market results, ratings, winners, payout claims, and player reviews are omitted until verified. All page styling and behavior are local; no framework or build step is required.
